想自己掌控？两种部署任选

同一份业务代码跑在两种宿主，不用改一行业务代码即可互相迁移，备份文件可互导。

Cloudflare Workers

D1 · KV · R2 · Cron，全球边缘运行

首次 wrangler deploy 自动创建 D1 / KV 与每小时定时触发，数据库结构启动时自动迁移；附件用的 R2 存储桶需先手工创建一次。

$ cp wrangler.toml.example wrangler.toml
$ npx wrangler r2 bucket create cron-files
$ npx wrangler deploy
查看 Cloudflare 部署文档

Docker 自部署

纯 Node + better-sqlite3，数据落本地目录

不依赖 Cloudflare，SQLite 模拟 D1/KV/R2，容器启动自动迁移；支持局域网与自有服务器。

$ docker compose up -d --build

常见问题

收费吗？

完全开源免费（MIT 协议）。自托管没有许可证费用：Cloudflare 免费额度即可运行，也可以用 Docker 部署在自己的服务器上。

我的数据存在哪？

数据始终在你自己手里：Cloudflare 部署时在你账号下的 D1 数据库与 R2 存储桶；Docker 部署时在本地数据目录。超管可随时全量导出 JSON，也能在不同实例之间导入迁移。

家人需要注册账号吗？

不需要。把专属免密链接发给家人，打开就能记录体重、加仓或录入资产；需要长期深度协作时，家人也可凭 8 位邀请码加入，仅访问你授权的模块。

定时推送是怎么实现的？

服务每小时唤醒一次，读取数据库中每个模块的推送配置，用平台无关的纯函数判断「此刻是否到点」。推送时刻在网页上随时可改，不用碰 cron 表达式或重新部署。
